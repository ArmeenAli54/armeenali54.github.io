ISSUES FOUND AND FIXED
-----------------------------------------------------------------------
1. [FIXED] Mobile navigation menu only 71px tall (did not cover screen).
   Root cause: the menu was nested inside .site-header, whose
   backdrop-filter makes the header the containing block for the menu's
   position: fixed; inset: 0, so the menu collapsed to the header height.
   Fix: moved the mobile menu out of the header to a direct child of
   <body>. Verified full-screen (844px) on 390x844 viewport.

2. [FIXED] Scroll progress bar never moved (stuck at 0px).
   Root cause: the onScroll handler was only invoked once on load and
   never attached to the window scroll event, so the progress bar, header
   scroll state, and back-to-top button never updated.
   Fix: registered the handler with window.addEventListener("scroll", ...,
   { passive: true }).

3. [FIXED] Scroll progress bar width logic applied twice.
   The handler set both the element width and a --p custom property used
   by ::after, so the fill understated progress and was invisible at the
   top of the page. Fix: keep only the --p custom property; the ::after
   now reads width: var(--p, 0%).

4. [FIXED] Two <h1> elements on the page (intro splash + hero), which
   produces an invalid document outline. Fix: intro splash name is now a
   div (was h1).

5. [FIXED] Galaxy dimmer overlay (.galaxy-overlay) was styled in CSS but
   missing from the HTML, so the background dimming never rendered.
   Fix: added the overlay div next to the canvas.

6. [FIXED] Contact form fields squeezed into 125px columns on mobile.
   Fix: the form row now stacks to a single column below 640px.

7. [FIXED] Focus not managed for overlays (accessibility).
   Opening the mobile menu / modals now moves focus into the dialog and
   restores focus to the triggering control on close. theme-color meta
   also corrected to match the background (#0a0a0c).
